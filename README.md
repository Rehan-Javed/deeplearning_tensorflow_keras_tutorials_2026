# deeplearning_tensorflow_keras_tutorials_2026

This repository contains my updated versions of older TensorFlow and Keras deep learning tutorials.

I am going through older code, updating it to work with current versions of TensorFlow and Keras, and keeping the examples as a learning reference.


## Purpose

The main purpose of this repository is to update older deep learning examples and understand how the code and APIs have changed over time.

The code is written and tested with modern Python/TensorFlow/Keras versions where possible.

## Note

Datasets and other large files are not included in the repository. The tutorials download the required datasets when needed.
